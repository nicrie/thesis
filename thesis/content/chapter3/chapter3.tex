Over the last decades, the field of climate science has seen a rapid increase in the volume and complexity of available data \cite{overpeck_climate_2011}. This trend is driven by the growing number of Earth observation satellites, the development of high-resolution climate models, and the increasing availability of citizen science data. As a result, researchers are faced with the challenge of analyzing vast amounts of data to extract meaningful insights about the Earth's climate and evnironment system. To address this challenge, dimensionality reduction methods have become an essential tool for gaining a better understanding of complex climate processes.

In the last chapter we briefly reviewed the theory for some commonly applied dimensionality reduction techniques in climate and environmental science. We showed that the combination of some useful and known extensions for PCA can be used to extend MCA to extract physically more meaningful patterns to analyze the shared dynamics between two distinct datasets. In this chapter, we will briefly describe

how the ever-growing volume of climate data produces practical challenges for researchers in the application of these techniques and how the open-source software ecosystem has responded to these challenges. Specifically, Section \ref{sec:xeofs:introduction} will introduce the \texttt{xeofs} library, a Python package that aims to facilitate the application of scalable dimensionality reduction techniques in climate science. By providing a user-friendly interface to traditional and state-of-the-art methods specific to the climate science context, \texttt{xeofs} enables researchers to leverage the power of advanced data analysis techniques without the need for specialized expertise. Climate science is a data-intensive field that relies on the analysis of large and complex datasets to understand the Earth's climate system. The increasing volume of available data poses a significant challenge for researchers, as traditional data analysis methods are often ill-suited to handle the scale and complexity of climate data. Additionally, the application of some of these techniques requires specialized knowledge and expertise, making them inaccessible to many researchers in the field. To bridge the gap between theory and scientific practice, software tools that lower the barrier to entry for non-experts are essential. Consequently, the field of climate science has seen a growing interest in the development of open-source tools that enable scalable and efficient data analysis. 

One of the biggest challanges in climate science today is the exploding volume of climate data and the resulting challenge of data analytics, i.e. the ability to extract meaningful information from large, complex datasets \cite{schnase_big_2016}. 
quotation: "the capacity to perform useful scientific analyses over large quantities of data in reasonable amounts of time."  (Schnase 2016). In many respects this is the biggest challenge, for without effective means for transforming large scientific data collections into meaningful scientific knowledge, our climate science mission fails.


To avoid that the analysis of these large data sets remains in the hand of a selective group of "Wissende", it effectively requires free, robust and scalable software tools that allow researchers without specialized knwodlege in programming to  simplifying and managing the vast amounts of data produced by climate models \cite{easterbrook_engineering_2009}. 

At the same time, over the last decade the open-source software (OSS) movement has gained significant momentum in the scientific community (Fig.~\ref{fig:xeofs:oss_overview}), with many researchers recognizing the benefits of OSS for fostering collaboration, improved transparency and reproducibility in scientific research \cite{krogh_community_2003,ince_case_2012,millman_developing_2018}. In particular, the high-level, general-purpose programming language Python has emerged as one of the most popular tools for scientific computing (Fig.~\ref{fig:xeofs:oss_overview}~B), due to its ease of use, extensive library support, and vibrant community of developers. Prime examples of the success of collaborative open-source software development in the scientific community are the \textit{NumPy} \cite{oliphant_python_2007,harris_array_2020}, \textit{SciPy} \cite{oliphant_python_2007,virtanen_scipy_2020} and \textit{Matplotlib} \cite{hunter_matplotlib_2007} libraries, which have become essential tools for scientific computing and visualizations in Python contributing to the deomcratization of scientific tools and techniques and spurring innvoation and scientific discovery \cite{sonnenburg_need_2007}.

Specifically for geoscience, the \textit{Pangeo} project \cite{pangeo} has been a key driver in promoting the use of open-source, high-quality scientific software for big data geoscience that allow researchers to handle petabyte-scale datasets on HPC and cloud platforms. Among others, two key cornerstones of the Pangeo software ecosystem are the open sources Python packages \textit{xarray} \cite{hoyer_xarray_2017} and \textit{dask} \cite{dask_development_team_dask_2016}. On the one hand side, xarray introduces labels in the form of dimensions, coordinates, and attributes on top of raw NumPy-like arrays, which allows for more intuitive, more concise, and less error-prone user experience. On the other hand side, dask faciliates parallel and distributed out-of-memory computing of datasets. Both tools in combination facilitate the analysis of large climate datasets by providing a scalable, efficient and simple way to handle the vast amounts of data produced by climate models, enabling researchers to focus on their scientific questions rather than technical challenges.


\section{Technical Barriers in Large-Scale and Multi-Dimensional Data Analysis}
\label{sec:xeofs:challenges}
Climate data analysis often involves the application of multivariate statsitical analysis and dimensionality reduction techniques to extract meaningful patterns from large labeled datasets. In Chapter~\ref{sec:theory} we only presented a tiny fraction of the vast universe of statistical methods for pattern identification in environment and climate science \cite{hannachi_patterns_2021,hsieh_introduction_2023}. Commonly, these methods rely on a fundamendal assumption: data can be represented as a compilation of observations (or samples) of certain variables (or features). This forms a 2D matrix. Yet, when examining data commonly encountered in Earth observations, be it climate simulations or satellite data, two characteristics of the data stand out:

\begin{enumerate}
    \item Multi-dimensional Nature: The data spans multiple dimensions, including spatial coordinates (longitude, latitude, height), time metrics (time, steps, forecast lead times), and other categories (variable types, sensors).
    \item Large Volume: These datasets are often enormous, frequently exceeding the memory capacity of a single computer.
\end{enumerate}

These two aspects have probably been the key drivers for the de-facto adoption of xarray and dask as the standard in the Python ecosystem when it comes to handling large, multi-dimensional data such as climate and Earth observations.

However, applying dimensionality reduction techniques like the ones discussed in Section~\ref{sec:theory} can pose challenges to researchers. The typical data processing pipeline for a climate data set (with dimesions time longitude and latitude) includes applying the desired variable weighting, removing invalid grid points (e.g. sea surface temperature with land grid cells), transforming the multidimensional dataset into a 2D matrix format using xarray which is then fed into packages like scikit-learn or dask for out-of-memory computations. These factors can make the analysis of large data sets cumbersome for the researcers. For instance, if one is interested in producing an approximate reconstruction of the original datafield using the first $M$ modes of PCA, after obtaining the 2D reconstruction (e.g. from scikit-learn) one has to reshape the data into its original in its multidimensioal form, reinsert land grid cells and unweight the data.  While manageable, this process is cumbersome, error-prone, and time-consuming task.

Earlier efforts in this regard have been the development of the python libraries \textit{eofs} \cite{dawson_eofs_2016} and \textit{xMCA} \cite{he_xmca_2020} which addressed PCA and MCA in particular. However, these libaries exhibit limitations when it comes to xarray and dask compatibility, which are essential for handling large climate datasets. For example, there is no support for xarray's fundamental \texttt{Dataset} object and neither of both makes use of randomized linear algebra \cite{halko_finding_2011,erichson_randomized_2019} to greatly speed up the computations. 

In addition, climate scienctist often require more than just the dimensionality reduction itself. They need to assess the significance of the extracted patterns, e.g. by performing a bootstrapping analysis to determine the significance of the modes. This requires additional code and expertise, which can be a barrier to entry for many researchers.

And finally, many classical and traditional methods developed over the last decades in and for climate science to extract meaningful patterns to the best of our knowldege have not been implemented in Python/xarray. This can make it difficult for researchers to apply these methods to their data, limiting the range of techniques available to them. 

\section{\textit{xeofs}: Extracting Meaningful Patterns from Climate Data}
\label{sec:xeofs:introduction}

Here we briefly introduce the \texttt{xeofs} library \cite{rieger_xeofs_2024}, a Python package that aims to facilitate the application of scalable dimensionality reduction techniques in climate science by providing a user-friendly interface to traditional and state-of-the-art methods specific to the climate science context. It provides a collection of widely-used dimensionality reduction techniques, focusing on methods prevalent in climate sciences. At the same time, the package development follows the common rules of scientific programming \cite{balaban_ten_2021}, clean coding and test design \cite{hunter-zinck_ten_2021}, version control \cite{perez-riverol_ten_2016}, robustness \cite{taschuk_ten_2017}, usability \cite{list_ten_2017}, documentation \cite{lee_ten_2018} and common rules of open software development \cite{prlic_ten_2012}. Specifically for Python, we xeofs largely follows the guidelines and best practices presented by the Pangeo project \cite{pangeo} and \textit{pyOpenSci} Packaging Guide \cite{wasser_pyopenscipython-package-guide_2024}.

The three key features of the \texttt{xeofs} library are:
\begin{description}
    \item[Multi-Dimensioal \& Labeled Data] Designed for xarray objects, xeofs applies dimensionality reduction to multi-dimensional data while maintaining data labels being based on xarray's DataArray and Dataset objects.
    \item[Out-of-Memory Computations] Supports large datasets via dask xarray objects, allowing researchers to analyze data that exceeds the memory capacity of a single computer and facilitates scaling up to terabyte computations on HPCs.
    \item[Computationally Efficient] Ensures computational efficiency, especially with large datasets through randomized linear algebra, which greatly speeds up the computations. A experimental comparison of the performance of the \texttt{xeofs} with the \texttt{eofs} library for conducting PCA on various data sizes shows that the xeofs librarby performance is about one order of magnitude faster for moderate to larger data sets (Fig.~\ref{fig:xeofs:performance}).
\end{description}

Secondary, additional nice-to-have features of the \texttt{xeofs} library include:

\begin{description}
    \item[Handling Missing Values] Can manage common cases of missing values such as masked ocean or land cells.
    \item[Weighted Analysis] Supports weighted analysis, allowing researchers to apply different weights to the data before performing dimensionality reduction. Binary TrueFalse switches for common weighting schemes (i.e. standard deviation, cosine of latitude; see Section~\ref{sec:theory:pca}) are provided.
    \item[Significance Testing] Provides a user-friendly interface for significance testing using bootstrapping \cite{efron_bootstrap_1979}.
    \item[Model Serialization] Allows users to save and load trained models in HDF5, Climate and Forecast (CF) convention-compatible netCDF4 \cite{hassell_data_2017} or cloud optimized Zarr formats \cite{alistair_miles_2020_3773450}.
\end{description}

All this is written in a modular, object-oriented way to make the package easily extendable to implement and include new dimensionality reduction methods.

All this is offered via an easy-to-use API that allows researchers to apply dimensionality reduction techniques to their climate data with minimal effort. The \texttt{xeofs} library is available on the Python Package Index (PyPI) and can be installed via pip. The source code is hosted on GitHub, where users can contribute to the development of the library and report issues or bugs. The library is licensed under the MIT license, making it free to use and modify for both academic and commercial purposes.
