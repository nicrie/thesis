\section{Principal Component Analysis}\label{sec:theory:pca}
is widely used in dimensionality reduction, data compression, feature extraction and visualization of high-dimensional data.

There are two definitions. PCA can be defined as
\begin{itemize}
    \item the orthogonal projection of the data onto a lower dimensional linear space, known as the principal subspace, such that the variance of the projected data is maximized (Hotelling 1933).
    \item the linear projection that minimizes the average projection cost, defined as the mean squared distance between the data points (Pearson, 1901).
\end{itemize}

Here we derive PCA from the maximum variance formulation~\cite[e.g.][pp.~561-563]{bishop_pattern_2006}
Consider a data set represented as a two dimensional $N\times D$ matrix $\bm{X}$ of $N$ 
observations with $D$ features such that the element $x_{ni}$ represents the 
$n$\textsuperscript{th} observations of the $i$\textsuperscript{th} feature.

of observations $\ab\{\bm{x}_n\}$ where $n=1,\dots,N$, and $\bm{x}_n$ is a 
Euclidean variabile with dimenesionality $D$.  Our goal is to project the data onto a space 
having dimensionality $M<D$ while maximizing the variance of the projected data. For the moment,
we shall assume that the value of $M$ is given. Later in this chapter, we shall consider techniques
to determine an appropriate value of $M$ from the data.

To begin with, consider the projection onto a one-dimensional space $(M=1)$. We can define the 
direction of this space using a $D$-dimensional vector $\bm{v}_1$, which for convenience we 
shall choose to be a unit vector so that $\bm{v}_1^T\bm{v}_1=1$. Note that we are only 
interested in the direction of $\bm{v}_1$, not its magnitude. Each data point $\bm{x}_n$ is
then projected onto a scaler value $\bm{v}_1^T\bm{x}_n$, and the variance of the projected data 
is given by

\begin{align}
    \bar{\bm{x}} = \frac{1}{N-1} \sum_{n=1}^{N} \bm{x}_n
\end{align}

and the variance of the projected data is given by 

\begin{align}
    \frac{1}{N-1} \sum_{n=1}^{N} \ab\{ \bm{v}_1^T\bm{x}_n - \bm{v}_1^T\bar{\bm{x}} \}^2 = \bm{v}_1^T\bm{S}\bm{v}_1
\end{align}

where $\bm{S}$ is the covariance matrix defined by

\[
\bm{S} = \frac{1}{N} \sum_{n=1}^{N} \ab( \bm{x}_n - \bar{\bm{x}}) \ab( \bm{x}_n - \bar{\bm{x}} )^T.
\]

We now maximize the projected variance $\bm{v}_1^T\bm{S}\bm{v}_1$ with respect to $\bm{v}_1$.
Since the maximization problem does not have a bounded (unique) solution, we need 
constrained maximization using our normalization condition from above $\bm{v}_1^T\bm{v}_1=1$. 
To enfore this constraint, we introduce a Lagrance multiplier that we shall denote by $\lambda_1$,
and then make an unconstrained maximization of 

\[
\bm{v}_1^T\bm{S}\bm{v}_1 + \lambda_1(1-\bm{v}_1^T\bm{v}_1).
\]

By setting the derivative with respect to $\bm{v}_1$ equal to zero, we see that this quantity 
will have a stationary point when 

\[
\bm{S}\bm{v}_1 = \lambda_1\bm{v}_1.
\]

which says that $\bm{v}_1$ must be an eigenvector of $\bm{S}$ and $\lambda_1$ the corresponding
eigenvalue. If we left-multiply by $\bm{v}_1^T$ and make use of the normalization condition, we
see that the variance is given by

\[
\bm{v}_1^T\bm{S}\bm{v}_1 = \lambda_1
\]

and so the variance will be a maximum when we set $\bm{v}_1$ equal to the eigenvector 
having the largest eigenvalue $\lambda_1$. The eigenvector is known as the first 
\textit{principal component}\footnote{Naming convention depends a lot on the scientific domain. For instance, the pair of eigenvectors (here $\bm{V}$) and corresponding data projections (here $\bm{U}$) are called the principal components and principal component scores in machine learning~\cite[e.g.][]{bishop_pattern_2006}, vector of coefficients/loadings and principal components in statistics~\cite[e.g.][]{jolliffe_principal_2002} or empirical orthogonal functions and principal components/expansion coefficients in climate science and meteorology~\cite[e.g.][]{storch_statistical_2003}. Here I try to be consistent and follow the convention used in machine learning.} of the data set.

We can define additional princiapl components in an incremental fashion by choosing each new 
direction to be that which maximizes the projected variance amongst all possible directions
orthongonal to those already considered. If we consider the general case of an $M$-dimensional
projection space, the optimal liner projection for which the variance of the projected data is
maximized is now defined by the $M$ eigenvectors $\bm{v}_1,\dots,\bm{v}_M$ of the data 
covariance matrix $\bm{S}$ corresponding to the $M$ largest eigenvalues 
$\lambda_1,\dots,\lambda_M$. This is easily shown using proof by induction (Appendix~\ref{sec:appendix1:pca_m_dim}), 
yielding the consice expression

\begin{align}\label{eq:theory:pca_eigenvector_decomposition}
    \bm{S}  \bm{V} = \bm{V} \bm{\Lambda},
\end{align}

where by construction the eigenvector matrix $\bm{V}$ is orthogonal, i.e. $\bm{V}^T\bm{V}=\bm{I}_M$.

Thus we see how the eigenvectors of $\bm{S}$ arise naturally when we try to find a new coordiante system
"along" regularities in the data. For what to do when the regularities in the data are not aligned in the
orthogonal directions, see Section~\ref{sec:theory:rotated_pca}.

From the spectral theorem for normal matrices~\cite[e.g.][p. 133]{horn_matrix_2012} it follows that the symmetric covariance matrix $\bm{S}$ can be decomposed
into the sum of the outer products of the eigenvectors $\bm{v}_i$ and the corresponding eigenvalues $\lambda_i$:

\begin{align}
    \bm{S} = \sum_{i=1}^M \lambda_i \bm{v}_i \bm{v}_i^T.
\end{align}

Therefore, each eigenvalue $\lambda_i$ represents the amount of variance described by each component 
which is typically expressed in form of a fraction $\gamma_i$ for the corresponding $i$\textsuperscript{th} component:

\begin{align}
    \gamma_i = \frac{\lambda_i}{\sum_{i=1}^M\lambda_i}
\end{align}


Projecting the data $\bm{X}$ onto the $M$ dimensional subspace thus provides the data representation in 
the projection space, called the raw \text{principal component scores}

\begin{equation}
    \bm{\tilde{U}} = \bm{X} \bm{V},
\end{equation}

which gives also the possibility to reconstruct the original data from (a subset of) the projected data:

\begin{align}\label{eq:theory:pca_reconstruction}
    \bm{X} = \bm{\tilde{U}} \bm{V}^T.
\end{align}


As we will see later, computing the eigenvector decomposition is not the most efficient way computationally seen.
A more efficient way to compute the eigenvectors involves the singular value composition (SVD)~\cite[e.g.][p. 150]{horn_matrix_2012} of the
data matrix

\begin{align}\label{eq:theory:pca_svd}
    \bm{X} = \bm{U}' \bm{\Sigma} {\bm{V}'}^T,
\end{align}

where $\bm{U}'$ and $\bm{V}'$ are respectively $N \times M$ and $M \times D$ unitary
matrices, i.e. ${\bm{U}'}^T \bm{U}' = {\bm{V}'}^T \bm{V}' = \bm{I}_M$ where $M \leq \min(N, D)$ is
the rank of $\bm{X}$ and $\bm{I}_M$ is the identity matrix of order $M$. The matrix $\bm{\Sigma}$ is a diagonal matrix of the singular values $\sigma_i$ of $\bm{X}$, i.e. $\sigma_1 \geq \sigma_2 \geq \dots \geq \sigma_M \geq 0$.

The covariance matrix $\bm{S}$ can be expressed in terms of the SVD as

\begin{align}
    \bm{S} = \frac{1}{N-1} \bm{X}^T \bm{X} = \frac{1}{N-1} \bm{V}' \bm{\Sigma}^T \bm{U}'^T \bm{U}' \bm{\Sigma} \bm{V}'^T = \bm{V} \bm{\Lambda} {\bm{V}}^T,
\end{align}

where, by comparison with \eqref{eq:theory:pca_eigenvector_decomposition}, $\bm{V} = \bm{V}'$ and $\bm{\Lambda} = \frac{1}{N-1} \bm{\Sigma}^T \bm{\Sigma}$. This last equation directly links the 
eigenvalues of the covariance matrix to the singular values of the data matrix:

\begin{align}
    \lambda_i = \frac{ \sigma_i^2}{N-1}.
\end{align}

Comparing \eqref{eq:theory:pca_reconstruction} with \eqref{eq:theory:pca_svd} shows that the raw principal component scores $\bm{\tilde{U}}$ 
can be normalized

\begin{align}
    \bm{U} \equiv \bm{U}'= \bm{\tilde{U}} \bm{\Sigma}^{-1} = \frac{1}{\ab(N-1)^{1/2}} \bm{\tilde{U}} \bm{\Lambda}^{-1/2},
\end{align}

so that $\bm{U}^T\bm{U} = \bm{I}_M$ and the principal component scores $\bm{U}$ are unitary, thus uncorrelated.

\paragraph{Physical interpretation in climate science} 

In climate science, PCA\footnote{In climate science, it is often refered to as Empirical Orthogonal Function (EOF) analysis.} 
is widely used to identify the dominant modes of variability in the atmosphere and oceans, where each mode is 
represented by a pair of principal components and the associated scores. 


\paragraph{Computational considerations}

Computationally, solving the eigendencomposition of the covariance matrix 
scales with $\order*{D^3}$ making it infeasable for modern data sizes in e.g. climate science 
where typical data sets\footnote{For instance, a single climate variable of ERA5, the go-to standard reference for state-of-the-art reanalysis climate data is distributed on a regular \ang{0.25} grid of Earth surface which translates to $D=\num{1036800}$ grid cells.}
are of the order $D=\order{10^6}$, but can be even much larger in practice.

In practice, alternative, more efficient algorithms involving the singular value demposition (SVD) or the 
power methods~\cite{golub_matrix_2013} haven been used instead from the beginning of the 
21st century onward. More recently, randomized low-rank approximation techniques~\cite{drineas_clustering_2004,halko_finding_2011} have allowed to considerably
reduce the computational complexity to $\order*{ND \log(M) + \ab(N+D)M^2}$ offering feasable alternatives for large, out-of-memory datasets 
(Table~\ref{tab:pca_algorithm_complexity}).

Finally, it is worth noting that there exists a closely related linear dimensionality
reduction technique called canonical correlation analysis, or CCA (Hotelling, 1936;
Bach and Jordan, 2002). Whereas PCA works with a single random variable, CCA
considers two (or more) variables and tries to find a corresponding pair of linear
subspaces that have high cross-correlation, so that each component within one of the
subspaces is correlated with a single component from the other subspace. Its solution
can be expressed in terms of a generalized eigenvector problem.
