\section{Principal Component Analysis}\label{sec:theory:pca}
Principal Component Analysis (PCA) is a technique that transforms a large set of variables into a smaller 
one that still contains most of the information in the original set by identifying the directions 
along which the data varies the most. As we will see, this is achieved by projecting the data onto the 
eigenvectors of the covariance matrix of the data, where these eigenvectors, or principal components, 
correspond to the directions of maximum variance, and the associated eigenvalues represent the 
magnitude of variance in these directions. This can be extremely helpful when dealing with high-dimensional data where the goal is dimensionality 
reduction, data compression, feature extraction or visualization of these high-dimensional data.

The first description of PCA can be traced back to \citet{pearson_lines_1901} in 1901 and \citet{hotelling_relations_1936} in 1936, but 
it was not until 1956 when \citet{lorenz_empirical_1956} popularized PCA in the field of meteorology under the term \textit{empirical orthogoanal function}
analysis\footnote{Indeed, until today EOF analysis seems to be the prefered term used in meteorology and climate science. We will stick to the more commonly used term PCA though.} 
Subsequently, PCA has been widely used in meteorology and climate science to identify the dominant modes of variability in the atmosphere and oceans with entire chapters of popular textbooks 
being dedicated to this technique \cite[e.g.][]{preisendorfer_principal_1988,storch_statistical_2003,hannachi_patterns_2021}. 

In the following we will quickly derive PCA from the maximum variance formulation\footnote{This is what \citet{hotelling_relations_1936} used to derive PCA. An alternative derivation is the minimum error formulation by \citet{pearson_lines_1901}, in which we seek a linear projection that minimizes the average projection cost, defined as the mean squared distance between the data points.},
\cite[e.g.][pp.~561-563]{bishop_pattern_2006}, in which the data is orthogonaly projected onto a lower dimensional linear space, known as the principal subspace, 
such that the variance of the projected data is maximized. Then we will discuss the main shortcomings of PCA in particular in the context of climate science and some of the most common ways to overcome these.

\subsection{Derivation based on Maximum Variance Formulation}
Consider a data set represented as a two dimensional $N\times D$ matrix $\bm{X}$ of $N$ 
observations with $D$ features such that the element $x_{ni}$ represents the 
$n$\textsuperscript{th} observations of the $i$\textsuperscript{th} feature.

of observations $\ab\{\bm{x}_n\}$ where $n=1,\dots,N$, and $\bm{x}_n$ is a 
Euclidean variabile with dimenesionality $D$.  Our goal is to project the data onto a space 
having dimensionality $M<D$ while maximizing the variance of the projected data. For the moment,
we shall assume that the value of $M$ is given. Later in this chapter, we shall consider techniques
to determine an appropriate value of $M$ from the data.

To begin with, consider the projection onto a one-dimensional space $(M=1)$. We can define the 
direction of this space using a $D$-dimensional vector $\bm{v}_1$, which for convenience we 
shall choose to be a unit vector so that $\bm{v}_1^T\bm{v}_1=1$. Note that we are only 
interested in the direction of $\bm{v}_1$, not its magnitude. Each data point $\bm{x}_n$ is
then projected onto a scaler value $\bm{v}_1^T\bm{x}_n$, and the variance of the projected data 
is given by

\begin{align}
    \bar{\bm{x}} = \frac{1}{N-1} \sum_{n=1}^{N} \bm{x}_n
\end{align}

and the variance of the projected data is given by 

\begin{align}
    \frac{1}{N-1} \sum_{n=1}^{N} \ab\{ \bm{v}_1^T\bm{x}_n - \bm{v}_1^T\bar{\bm{x}} \}^2 = \bm{v}_1^T\bm{S}\bm{v}_1
\end{align}

where $\bm{S}$ is the covariance matrix defined by

\[
\bm{S} = \frac{1}{N} \sum_{n=1}^{N} \ab( \bm{x}_n - \bar{\bm{x}}) \ab( \bm{x}_n - \bar{\bm{x}} )^T.
\]

We now maximize the projected variance $\bm{v}_1^T\bm{S}\bm{v}_1$ with respect to $\bm{v}_1$.
Since the maximization problem does not have a bounded (unique) solution, we need 
constrained maximization using our normalization condition from above $\bm{v}_1^T\bm{v}_1=1$. 
To enfore this constraint, we introduce a Lagrance multiplier that we shall denote by $\lambda_1$,
and then make an unconstrained maximization of 

\[
\bm{v}_1^T\bm{S}\bm{v}_1 + \lambda_1(1-\bm{v}_1^T\bm{v}_1).
\]

By setting the derivative with respect to $\bm{v}_1$ equal to zero, we see that this quantity 
will have a stationary point when 

\[
\bm{S}\bm{v}_1 = \lambda_1\bm{v}_1.
\]

which says that $\bm{v}_1$ must be an eigenvector of $\bm{S}$ and $\lambda_1$ the corresponding
eigenvalue. If we left-multiply by $\bm{v}_1^T$ and make use of the normalization condition, we
see that the variance is given by

\[
\bm{v}_1^T\bm{S}\bm{v}_1 = \lambda_1
\]

and so the variance will be a maximum when we set $\bm{v}_1$ equal to the eigenvector 
having the largest eigenvalue $\lambda_1$. The eigenvector is known as the first 
\textit{principal component}\footnote{Naming convention depends a lot on the scientific domain. For instance, the pair of eigenvectors (here $\bm{V}$) and corresponding data projections (here $\bm{U}$) are called the principal components and principal component scores in machine learning~\cite[e.g.][]{bishop_pattern_2006}, vector of coefficients/loadings and principal components in statistics~\cite[e.g.][]{jolliffe_principal_2002} or empirical orthogonal functions and principal components/expansion coefficients in climate science and meteorology~\cite[e.g.][]{storch_statistical_2003}. Here I try to be consistent and follow the convention used in machine learning.} of the data set.

We can define additional princiapl components in an incremental fashion by choosing each new 
direction to be that which maximizes the projected variance amongst all possible directions
orthongonal to those already considered. If we consider the general case of an $M$-dimensional
projection space, the optimal liner projection for which the variance of the projected data is
maximized is now defined by the $M$ eigenvectors $\bm{v}_1,\dots,\bm{v}_M$ of the data 
covariance matrix $\bm{S}$ corresponding to the $M$ largest eigenvalues 
$\lambda_1,\dots,\lambda_M$. This is easily shown using proof by induction (Appendix~\ref{sec:appendix1:pca_m_dim}), 
yielding the consice expression

\begin{align}\label{eq:theory:pca_eigenvector_decomposition}
    \bm{S}  \bm{V} = \bm{V} \bm{\Lambda},
\end{align}

where by construction the eigenvector matrix $\bm{V}$ is orthogonal, i.e. $\bm{V}^T\bm{V}=\bm{I}_M$.

Thus we see how the eigenvectors of $\bm{S}$ arise naturally when we try to find a new coordiante system
"along" regularities in the data. For what to do when the regularities in the data are not aligned in the
orthogonal directions, see Section~\ref{sec:theory:rotated_pca}.

From the spectral theorem for normal matrices~\cite[e.g.][p. 133]{horn_matrix_2012} it follows that the symmetric covariance matrix $\bm{S}$ can be decomposed
into the sum of the outer products of the eigenvectors $\bm{v}_i$ and the corresponding eigenvalues $\lambda_i$:

\begin{align}
    \bm{S} = \sum_{i=1}^M \lambda_i \bm{v}_i \bm{v}_i^T.
\end{align}

Therefore, each eigenvalue $\lambda_i$ represents the amount of variance described by each component 
which is typically expressed in form of a fraction $\gamma_i$ for the corresponding $i$\textsuperscript{th} component:

\begin{align}
    \gamma_i = \frac{\lambda_i}{\sum_{i=1}^M\lambda_i}
\end{align}


Projecting the data $\bm{X}$ onto the $M$ dimensional subspace thus provides the data representation in 
the projection space, called the raw \text{principal component scores}

\begin{equation}
    \bm{\tilde{U}} = \bm{X} \bm{V},
\end{equation}

which gives also the possibility to reconstruct the original data from (a subset of) the projected data:

\begin{align}\label{eq:theory:pca_reconstruction}
    \bm{X} = \bm{\tilde{U}} \bm{V}^T.
\end{align}


As we will see later, computing the eigenvector decomposition is not the most efficient way computationally seen.
A more efficient way to compute the eigenvectors involves the singular value composition (SVD)~\cite[e.g.][p. 150]{horn_matrix_2012} of the
data matrix

\begin{align}\label{eq:theory:pca_svd}
    \bm{X} = \bm{U}' \bm{\Sigma} {\bm{V}'}^T,
\end{align}

where $\bm{U}'$ and $\bm{V}'$ are respectively $N \times M$ and $M \times D$ unitary
matrices, i.e. ${\bm{U}'}^T \bm{U}' = {\bm{V}'}^T \bm{V}' = \bm{I}_M$ where $M \leq \min(N, D)$ is
the rank of $\bm{X}$ and $\bm{I}_M$ is the identity matrix of order $M$. The matrix $\bm{\Sigma}$ is a diagonal matrix of the singular values $\sigma_i$ of $\bm{X}$, i.e. $\sigma_1 \geq \sigma_2 \geq \dots \geq \sigma_M \geq 0$.

The covariance matrix $\bm{S}$ can be expressed in terms of the SVD as

\begin{align}
    \bm{S} = \frac{1}{N-1} \bm{X}^T \bm{X} = \frac{1}{N-1} \bm{V}' \bm{\Sigma}^T \bm{U}'^T \bm{U}' \bm{\Sigma} \bm{V}'^T = \bm{V} \bm{\Lambda} {\bm{V}}^T,
\end{align}

where, by comparison with \eqref{eq:theory:pca_eigenvector_decomposition}, $\bm{V} = \bm{V}'$ and $\bm{\Lambda} = \frac{1}{N-1} \bm{\Sigma}^T \bm{\Sigma}$. This last equation directly links the 
eigenvalues of the covariance matrix to the singular values of the data matrix:

\begin{align}
    \lambda_i = \frac{ \sigma_i^2}{N-1}.
\end{align}

Comparing \eqref{eq:theory:pca_reconstruction} with \eqref{eq:theory:pca_svd} shows that the raw principal component scores $\bm{\tilde{U}}$ 
can be normalized

\begin{align}
    \bm{U} \equiv \bm{U}'= \bm{\tilde{U}} \bm{\Sigma}^{-1} = \frac{1}{\ab(N-1)^{1/2}} \bm{\tilde{U}} \bm{\Lambda}^{-1/2},
\end{align}

so that $\bm{U}^T\bm{U} = \bm{I}_M$ and the principal component scores $\bm{U}$ are unitary, thus uncorrelated.


\paragraph{Computational considerations}

Computationally, solving the eigendencomposition of the covariance matrix 
scales with $\order*{D^3}$ making it infeasable for modern data sizes in e.g. climate science 
where typical data sets\footnote{For instance, a single climate variable of ERA5, the go-to standard reference for state-of-the-art reanalysis climate data is distributed on a regular \ang{0.25} grid of Earth surface which translates to $D=\num{1036800}$ grid cells.}
are of the order $D=\order{10^6}$, but can be even much larger in practice.

In practice, alternative, more efficient algorithms involving the singular value demposition (SVD) or the 
power methods~\cite{golub_matrix_2013} haven been used instead from the beginning of the 
21st century onward. More recently, randomized low-rank approximation techniques~\cite{drineas_clustering_2004,halko_finding_2011} have allowed to considerably
reduce the computational complexity to $\order*{ND \log(M) + \ab(N+D)M^2}$ offering feasable alternatives for large, out-of-memory datasets 
(Table~\ref{tab:pca_algorithm_complexity}).





\paragraph{Shortcomings} 
Despite its popularity and wide applicability, PCA has several limitations and potential drawbacks that should be considered when using this technique:
\begin{enumerate}
    \item \textbf{Linearity assumption:} PCA assumes that the data's underlying structure is linear, which may not always hold true, especially in complex systems like climate data where nonlinear relationships can be significant.
    \item \textbf{Interpretability of principal components:}  In addition to the linearity assumption, the dominant modes of variability are represented in an orthgonal subspace spanned by the principal components. This orthogonality is a mathematical construction that may not always correspond to the physical reality of the data, potentially leading to misinterpretations of the results (see Section~\ref{sec:theory:rotated_pca}).
    \item \textbf{Variance focus:} Capturing the directions of maximum variance may not always correspond to the most important features for a given application, potentially overlooking critical but less variable information. 
    \item \textbf{Static nature:} As a static method PCA does not account for temporal dynamics or changes over time, which can be particularly limiting in climate science where time evolution is a key aspect.
    \item \textbf{Sensitivity to outliers:} PCA can be sensitive to outliers, as extreme values can disproportionately influence the principal components, leading to misleading results.
    \item \textbf{Sensitivity to scaling:} The results are sensitive to the scaling of the input data, meaning that variables with larger ranges can dominate the principal components unless the data is appropriately standardized.
    \item \textbf{Loss of information:} Not a shortcoming by itself because it's sometime the goal of PCA, but it should be taked into account that by reducing dimensionality, PCA inherently discards some information, which might lead to the loss of important details that could be crucial for accurate analysis and interpretation in specific applications.
\end{enumerate}

Over the last decades a plethora of modifications and extensions have been proposed to overcome these limitations. We only mention a few here that are particularly relevant in the context of climate science.
These include various forms of kernel PCA \cite{webb_approach_1996,scholkopf_nonlinear_1998,bueso_nonlinear_2020} to adress the linearity assumption, rotated \cite{richman_rotation_1986} and sparse \cite{hannachi_search_2006} PCA for interpretability, 
robust PCA \cite{candes_robust_2011} to address the sensitivity to outliers, and extended \cite{weare_examples_1982,broomhead_extracting_1986} and complex \cite{barnett_interaction_1983,horel_complex_1984} PCA to account for temporal dynamics. 
Although not strictly a form of PCA, eigenmethods like optimal persistence analysis (OPA) \cite{delsole_optimally_2001,delsole_low-frequency_2006}, which allows to filter for spatial patterns linked to increased persistence, and Principal Oscillation Pattern (POP) analysis \cite{hasselmann_pips_1988} 
that provides a mean to analyze dynamical systems, are an example of related appraoches with the goal to gain insights about the dominant pattern of a physical field in climate science.

In the following sections, we will discuss some of the shortcomings and proposed solutions in more detail: 
in particular we will discuss how an additional rotation of the PCA solution can help address the challenge of physical interpretability (Section~\ref{sec:theory:rotated_pca}) and 
how complexifying the data provides a means to better understand time evolution patterns (Section~\ref{sec:theory:hilbert_pca}).

\subsection{Rotated PCA}\label{sec:theory:rotated_pca}
The physical interpretation of the principal componetns is limited by two fundamental properties of PCA.

First, while it is often possible to clearly associate the first components with a 
known physical process, this is much more difficult with the second (and higher-order)
components because it is constrained to be orthogonal to the first component. However,
real-word processes do not need to have orthogonal patterns or uncorrelated scores. 

Secondly, while benefitial in many cases, the ability for efficient data compression inherent in the dimesionality reduction of PCA typically 
leads to the principal components being dense, i.e. all elements of the eigenvectors are non-zero. 
This can make the interpretation of the principal components difficult.

It is mainly due to these two properties that lead to a variety of undesired effects in the context of climate science. For instance, \citet{richman_rotation_1986} 
describes four effects, namely domain shape dependence, subdomain instability, sampling errors and non-intuitive patterns. 
The first two are a direct consequence of the orthogonality constraint,
which for rectangular domains -- like a regular longitude-latitude grid -- leads to a set of patterns known as the Buell patterns \cite{richman_rotation_1986} consisting 
of a positive pattern for the first component, subsequently followed by increasing polar i.e. bipole, tripole, quadrupole etc. patterns for the subsequent components 
(Figure~\ref{fig:theory:pca_buell_patterns}), which upon shifting the domain can lead to a completely different set of patterns. 

The third effect is related to fact that finite sample sizes will always lead to a sampling error \cite{north_sampling_1982}, 
which can be severe when eigenvalues are closely spaced. 

The fourth effect is a logical conclusions from the first three, but which is enhanced by the dense nature of the principal components which is often not representative of the underlying physical processes,
which are often more regionalized. 

To address these limitations, rotated PCA techniques \cite[e.g.][]{richman_rotation_1986} have been developed with the goal to produce "simpler" patterns 
in the hope that these would automatically better align with the underlying physical processes.

This simplicity is vaguely defined in a heuristic manner, but typically refers to patterns that are more localized, less dense, and more physically interpretable.

Thurstone states that all of the common variance of a variable should be accounted for by fewer than r common factors.

The underlying idea is to find a rotation matrix $\bm{R}$ that rotates the principal components $\bm{V}$ to a new set of components $\bm{V}_R$ that are more physically interpretable.

Finally, it is worth noting that there exists a closely related linear dimensionality
reduction technique called canonical correlation analysis, or CCA (Hotelling, 1936;
Bach and Jordan, 2002). Whereas PCA works with a single random variable, CCA
considers two (or more) variables and tries to find a corresponding pair of linear
subspaces that have high cross-correlation, so that each component within one of the
subspaces is correlated with a single component from the other subspace. Its solution
can be expressed in terms of a generalized eigenvector problem.
